# JobLovesMe Agent 全栈设计白皮书 (v2.2 - 工业级增强版)

## 一、 项目概览 (总)

### 1.1 项目背景
在激烈的求职竞争中，候选人往往面临简历投递效率低、面试准备不充分、面经信息杂乱等痛点。**JobLovesMe Agent** 旨在构建一个极简风格、高性能、可量化的全栈 AI 助手，通过 RAG (检索增强生成) 技术深度结合个人简历、职位描述 (JD) 和全网优质面经，为用户提供从“简历打磨”到“打招呼”再到“模拟面试”的全流程赋能。

### 1.2 核心模块划分
- **鉴权与安全系统**：基于 JWT 的多用户隔离、PII 隐私脱敏与安全防护。
- **简历与自我推荐系统**：PDF 解析、基于 JD 上下文的精准推荐语生成及语义缓存。
- **面经采集系统**：基于 Python 爬虫、Redis Stream 异步驱动与流式排序的高质量数据入库。
- **面经查询系统 (Eino RAG)**：基于 Eino 框架编排的 Hybrid Search 与 Rerank 精准检索。
- **模拟面试系统 (Eino Agent)**：基于 Eino 状态机编排、带技术雷达图评估的 AI 面试教练。
- **监控大盘系统**：全方位的业务指标、AI 质量 (RAGAS)、Token 成本与系统资源观测。

## 二、 系统详细设计 (分)

### 2.1 鉴权与安全系统设计
- **核心协议**: 使用 **JWT (JSON Web Token)** 实现无状态身份验证。
- **PII 脱敏 (Privacy Preservation)**: 在简历发送至 LLM 之前，集成脱敏中间件，自动将姓名、手机号、邮箱替换为占位符（如 `[Candidate Name]`），确保隐私合规。
- **用户隔离**: 数据库层面强制绑定 `user_id`，实现租户级逻辑隔离。

### 2.2 自我推荐生成系统设计 (打招呼)
- **简历解析**: 采用 Go 高性能库提取 PDF 原始文本，并持久化于 `resumes` 表。
- **语义缓存 (Semantic Cache)**: 
  - 使用 Redis 向量搜索 (Redis VL) 存储高频 JD 的推荐语结果。
  - 命中相似 JD 时直接返回缓存，响应耗时从 10s 级降至 100ms 级，且节省 Token 成本。
- **Eino Chain 编排**: `Resume_Loader -> JD_OCR -> Prompt_Template -> DeepSeek_LLM -> SSE_Output`。

### 2.3 面经爬虫系统设计 (流式入库)
- **异步驱动**: Go 后端通过 **Redis Stream** 下发任务，Python 爬虫作为 Consumer 异步处理。
- **流式排序算法 (Top-K)**: 内存维护容量为 50 的最小堆，实时计算质量分 $S$，确保即使在处理 10w+ 数据时内存依然平稳。

### 2.4 面经查询系统设计 (Eino RAG Graph)
- **Hybrid Search**: 融合 Milvus 向量搜索与 MySQL 关键词搜索，通过 RRF 算法提升召回率。
- **A/B Test 架构**: 支持对比“基础向量检索”与“Eino Rerank 优化”后的检索效果，量化提升指标。
- **Bad Case 闭环**: 建立坏例收集机制，通过调整 Rerank 阈值或 Prompt 持续迭代。

### 2.5 面试模拟系统设计 (Eino Stateful Agent)
- **状态管理**: 利用 Eino 状态机维护面试进度、对话历史 (Memory)。
- **多维度评估与技术雷达**: 
  - **量化指标**: 表达流畅度、项目深度、基础知识扎实度。
  - **技术雷达图**: 根据 JD 动态提取考核点（如并发、分布式、数据库）并展示得分分布。
- **面评闭环**: 自动根据弱点生成“针对性学习路径”，实现服务闭环。

### 2.6 监控大盘系统设计
- **业务看板**: 成长趋势线图、技术雷达、面经覆盖率。
- **AI 质量看板**: Token 成本、RAGAS 指标（Faithfulness, Recall）、用户修改率。
- **工程看板**: 磁盘占用、爬虫成功率、API 延迟 P99、缓存命中率。

## 三、 方案总结与价值 (总)

### 3.1 方案选型考量
本项目在架构上选择了 **Go (Gin) + Eino** 作为核心，结合 **Python 爬虫**。通过引入 **语义缓存** 与 **流式排序**，解决了 AI 应用中常见的成本与性能痛点。

### 3.2 项目核心价值
- **对用户**: 提供极具“专业度”和“反馈深度”的求职辅导，通过技术雷达感知真实短板。
- **对工程**: 沉淀了一套基于 Go 生态的**生产级 Agent 开发范式**，涵盖了编排、评估、治理的全链路。

### 3.3 方案优势
1. **架构深度**: 引入 Eino 编排与语义缓存，体现了对成本和工程极致的追求。
2. **闭环治理**: 将 Bad Case 分析与 A/B Test 纳入流程，确保 AI 效果的可持续进化。
3. **隐私合规**: 内置 PII 脱敏逻辑，符合 ToC 产品的安全标准。

### 3.4 个人成长与提升
通过本项目，我不仅掌握了 **Go 全栈开发** 与 **Eino 编排**，更在 **AI 系统治理 (Evaluation, Cache, Security)** 方面积累了宝贵的实战经验。这标志着我从“功能开发者”向“**AI 原生应用架构师**”迈出了坚实的一步。
